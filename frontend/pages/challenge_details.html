Challenge Scope & Objective

Replicate this modern high-converting SaaS landing page. The composition features a bold typographic header, dual action CTA buttons with cyan-indigo gradients, a floating app preview mockup with subtle tilt perspective, a four-column statistics bar, and a core capabilities card grid.

Ensure proper structural hierarchy, smooth micro-interactions, and flawless fluidity from wide desktops down to narrow mobile viewports.

task_alt

Key Acceptance Criteria

  • check_circle Hero & Floating Canvas: Implement the gradient glow background, primary CTA button with specular inner bevel, and the multi-layered dashboard preview mock.
  • check_circle Stats Row Layout: 4-column balanced metrics row (150%, 99.99%, 50k+, 24/7) gracefully wrapping on mobile devices.
  • check_circle Feature Cards Grid: 2x2 modular matrix with icon pills, subtle card background differentiation, and refined typography hierarchy.
  • check_circle Luminescent Styling: Clean dark surfaces without heavy generic borders, using background-level luminance contrast and soft glows.
